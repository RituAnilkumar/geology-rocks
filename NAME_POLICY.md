# Name and logo policy

The code and content of Geology Rocks are free to use, change and share under
their licences. The **name "Geology Rocks" and its logo** identify this
particular project, so that users know what they are getting.

- You may use the name to refer to this project (articles, teaching, reviews,
  "based on Geology Rocks").
- Unmodified builds from this repository may use the name and logo.
- If you distribute a **substantially modified version** (a fork), please give
  it a different name and logo, and state that it is based on Geology Rocks.
- Please don't use the name or logo in ways that suggest endorsement of
  products or services by this project.

This policy is a request in the spirit of open source, not a restriction on
the rights the licences give you.
