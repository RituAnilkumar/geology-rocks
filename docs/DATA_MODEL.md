# Data model

Two forms of the same data:
- **Source form** (in git, edited by people): YAML, Markdown, GeoJSON/GeoPackage.
- **Built form** (on the phone): SQLite + PMTiles, generated by `pipeline/`.

JSON Schemas for every source file type are in `schemas/`.

## Common conventions

- **IDs**: lowercase dotted paths, permanent. Taxa: `rock.<class>.<group>...`,
  characters `char.<name>`, states `<char-tail>.<state>` within a character,
  minerals `mineral.<name>`, named units `nu.<name>`, kit `kit.<name>`.
- **Translatable text**: `{en: "...", cy: "..."}`; `en` (British English) required.
- **Review block** on every content item:
  `review: {status: draft|in_review|approved, reviewer: <name|null>, date: <YYYY-MM-DD|null>, notes: <optional>}`
- **Deprecation**: `deprecated: true`, `replaced_by: <id>`; never delete or rename IDs.

## 1. Taxonomy node (`content/core/taxonomy/**.yaml`)

```yaml
id: rock.igneous.plutonic.felsic.granite
level: L4                                   # L0..L4
parents: [rock.igneous.plutonic.felsic]     # usually one; rarely two
order: 10                                   # display order among siblings
name: {en: Granite}
field_label: {en: "coarse-grained felsic plutonic rock"}
synonyms: [granitoid]
refs: {bgs_rcs: TODO, iugs: "QAPF field 3"}
tags: [felsic, coarse, crystalline]
page: granite                               # content/core/pages/granite.md
characters:                                 # matrix row: P(state | taxon)
  char.texture: {interlocking: 0.92, clastic: 0.02, glassy: 0.01, foliated_banded: 0.05}
  char.grain_size: {coarse: 0.85, medium: 0.13, fine: 0.02, glassy: 0.0}
  char.acid_reaction: inherit
review: {status: draft, reviewer: null, date: null}
```

Rules: for single-choice characters values sum to 1; for multi-select
characters each value is an independent P(present). A character a taxon does
not list takes the values of its **nearest ancestor that lists it**
(`inherit` says the same thing explicitly). Only a character listed nowhere
up the tree is uninformative for that taxon. (Clarified in M2; see DECISIONS.md.)

L0 roots: `rock` (natural rock), `weathering` (weathering product),
`human` (human-made). `sediment` (loose) is reserved.

Leaves are usually L4, but some branches are shallower (e.g. `human.brick`
is an L1 leaf). Each child's level is exactly one below its parent's.

## 2. Character (`content/core/characters/*.yaml`)

```yaml
id: char.grain_size
order: 30
kind: single            # single | multi (multi = several states can be true)
question: {en: "How big are the grains or crystals?"}
how_to: {en: "Compare with the grain-size card in good light. Use a hand lens for fine grains."}
kit_required: [kit.grain_size_card]
applies_from: L0        # earliest level at which it's worth asking
cost: 1                 # 1 = look, 2 = simple test, 3 = kit test, 4 = destructive
states:
  - id: coarse
    label: {en: "Coarse — most grains bigger than 2 mm"}
    hint_media: TODO
    tells_you: {en: "..."}
  - id: medium
    ...
review: {status: draft}
```

## 3. Mineral (`content/core/minerals/*.yaml`)

```yaml
id: mineral.k_feldspar
name: {en: "Potassium feldspar (K-feldspar)"}
properties:
  hardness_mohs: [6, 6.5]
  lustre: vitreous
  cleavage: {en: "Two good cleavages at about 90°"}
  colours: [pink, cream, white, salmon]
  streak: white
how_to_spot: {en: "..."}
look_alikes: [{id: mineral.plagioclase, how_to_tell: {en: "..."}}]
indicates: [{taxon: rock.igneous.plutonic.felsic, strength: strong}]
hint_media: [TODO]
review: {status: draft}
```

Minerals feed the rock key through `char.mineral_*` multi-select characters
(e.g. `char.minerals_visible` with options quartz, k_feldspar, plagioclase,
mica, dark_minerals, calcite, garnet, olivine ...).

## 5. Media record

Media files live in `content/core/media/` (or a pack's `media/`). Each has a
companion `<file>.license` (REUSE) and an entry in `media.yaml`:

```yaml
- file: hints/grain_coarse.webp
  licence: CC-BY-SA-4.0
  author: "..."
  source: original          # or URL
  alt_text: {en: "..."}
  depicts: [rock.igneous.plutonic.felsic.granite, "char.grain_size:coarse"]
  review: {status: draft}
```

## 6. Pack files (`content/packs/<pack>/`) — see PACK_SPEC.md

- `manifest.yaml` — id, name, extent (bbox), version, core requirement,
  sources + licences, layers (offline/online), map style flags.
- `crosswalk.yaml` — map unit code → taxon probabilities + named unit.
- `context.yaml` — find-context weights; clast suites per zone.
- `named_units/*.yaml` — L5 entries.
- `learn/` — story chapters, sites, walks (Markdown + YAML).
- `collecting/` — zones (GeoJSON) + rules YAML.

## 8. Built core database (`core.sqlite`) — indicative tables

```sql
taxon(id, level, order_idx, name_key, field_label_key, page_id, review_status)
taxon_parent(taxon_id, parent_id)
taxon_tag(taxon_id, tag)
character(id, order_idx, kind, question_key, how_to_key, applies_from, cost)
character_kit(character_id, kit_id)
state(id, character_id, order_idx, label_key, tells_you_key, hint_media_id)
likelihood(taxon_id, state_id, p)          -- leaves only, inheritance resolved
mineral(id, name_key, page_id, ...)
mineral_indicates(mineral_id, taxon_id, strength)
kit(id, name_key, safety_key, where_key, media_id)
text(key, lang, value)                     -- ALL user-facing strings
page(id, body_key, lookalikes_key, uses_key)
glossary(term_key, definition_key)
timescale(id, name_key, ma_start, ma_end, colour)
media(id, path, licence_spdx, author, source, alt_text_key, review_status)
meta(core_version, schema_version, built_at)
```

Exports: CSV and GeoJSON (flattened), KML, zip of photos.
