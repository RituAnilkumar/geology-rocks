Write the milestone report described in CLAUDE.md ("Who you are working with",
point 4) for the milestone we've just finished. Use plain language; I am not a
developer.

3. "What to try" checklist, including things that should fail
4. Draft content created or changed that needs my review (list files)
5. Decisions made (and confirm they're logged in docs/DECISIONS.md)
6. Known limitations
7. What's next (the next milestone from docs/ROADMAP.md)

Before writing, run all checks and make sure they pass; report any that don't.
