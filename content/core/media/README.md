# Media

Every media file needs:
1. An entry in `media.yaml` (licence SPDX id, author, source, alt text, what it depicts, review status).
2. REUSE licence information: a `<file>.license` companion file, unless covered by `REUSE.toml`.

Only free licences: CC0-1.0, CC-BY-4.0, CC-BY-SA-4.0, OGL-UK-3.0, ODbL-1.0 (data), public domain.
No NC or ND material. Follow the photo protocol in `docs/CONTENT_GUIDE.md`.
